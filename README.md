# Cyber Security Project 3 – Phishing Awareness Analysis
In this project, I analyzed 7 different sample emails to identify phishing indicators and security red flags.
For each email, I checked:
- Sender and domain mismatch
- Suspicious or fake URLs
- Urgency and pressure-based wording
- Dangerous attachments
- Impersonation attempts
- Payment or sensitive information requests
- Lookalike domains
- Social engineering techniques
- Suspicious buttons and login requests

After reviewing each email, I classified it as **Safe, Suspicious, or Malicious** and also defined the appropriate action such as **Close, Warn User, or Block & Escalate**.

This project helped me understand how phishing attacks use human psychology, fake domains, urgency, authority, and malicious attachments to trick users.
